# Xray native Android engine

The app uses the upstream XTLS/libXray Android binding. The generated AAR is not committed.

## Build

On Linux/macOS with JDK 17, Go, Python 3, Git, Android SDK and NDK:

```bash
./scripts/build-libxray-android.sh
```

The script pins upstream libXray v26.11.9 and runs its Android build script. Gradle includes `app/libs/libXray.aar` when present.

## Runtime

The existing `KupalVpnService` establishes a `VpnService.Builder` TUN, passes its FD through Xray config, invokes libXray, and registers socket protection and DNS callbacks. The AAR is generated by CI. The generated binding API names and TUN handoff still require an actual Android build and device test.
